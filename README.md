# 컨테이너 적재 시방서

ISO 건식 컨테이너에 직육면체 화물을 넣고, 3D 적재 계획과 한국어 **적재 시방서 PDF**를 만드는 웹 앱입니다.

- 컨테이너: 20ft Dry, 40ft Dry, 40ft HC, 45ft HC (내부 L×W×H·용적)
- 화물: 품명, 치수(mm 또는 cm), 수량, 선택 중량
- 적재: 익스트림 포인트 / 최대잔여공간 휴리스틱 중 더 나은 안
- 미리보기: Three.js, 상자 클릭 강조, 선적·하단 순서 슬라이더
- 시방서: 컨테이너 제원, 화물 목록, 활용률, 좌표·회전, 층별 메모, 작성일. 한글 글꼴(Nanum Gothic) 임베드.

인증·데이터베이스는 없습니다. 계산은 브라우저에서 수행합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://127.0.0.1:43127](http://127.0.0.1:43127) 을 엽니다.

```bash
npm run build
npm start
npm run verify
```

`verify`는 샘플 화물 적재(겹침·이탈 없음)와 한글 PDF 생성을 검사합니다.

## 사용 방법

1. 컨테이너 종류를 고릅니다. 3D 뷰에 빈 컨테이너가 보입니다.
2. 화물 행을 입력하거나 **예시 화물 넣기**를 누릅니다. 치수 단위는 mm/cm 중 하나로 통일하세요.
3. **적재 계획 계산**을 누릅니다.
4. 상자를 클릭해 강조하고, 슬라이더로 적재 순서를 단계별로 봅니다.
5. **시방서 PDF 내려받기**로 `적재시방서-{컨테이너}-{날짜}.pdf`를 저장합니다.

## 선택: PDF 해설

프로젝트 루트에 `.env.local`을 만들고 `OPENAI_API_KEY`를 넣으면, 시방서에 짧은 한국어 적재 해설이 붙습니다. 키가 없으면 해설 없이 시방서만 만듭니다.

## 기술

Next.js, TypeScript, Tailwind CSS, shadcn/ui, React Three Fiber, pdf-lib.
